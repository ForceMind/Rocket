# Rocket Crash Platform 后台运营指南

## 1. 后台入口

本地地址：

```text
http://localhost:3000/admin
```

当前 MVP 后台免密码，适合本地开发和演示，不适合公网生产环境。

## 2. 顶部指标

| 指标 | 说明 |
| --- | --- |
| 玩家数 | 已创建的真实玩家数量 |
| 总下注 | 历史 + 当前局真实玩家下注金额 |
| 总返还 | 历史 + 当前局真实玩家返还金额 |
| 平台盈亏 | 真实玩家下注 - 真实玩家返还 |
| 奖池余额 | 当前奖池可承受返还余额 |
| 本局机器人 | 当前局机器人下注人数 |
| 玩家余额 | 所有真实玩家余额总和 |

口径：

- 机器人下注不计入总下注。
- 机器人返还不计入总返还。
- 机器人输赢不计入平台盈亏。
- 机器人只统计数量，用于演示活跃度。

## 3. 当前回合

当前回合显示：

- 回合阶段。
- 回合 ID。
- 当前倍率。
- 预设爆点。
- 奖池承受上限。
- Seed Hash。

说明：

- 后台可以看到预设爆点。
- 玩家端飞行阶段不显示预设爆点。
- 强制爆炸会把回合标记为 `forced`。

## 4. 参数说明

### 4.1 时间参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 下注倒计时 ms | `7000` | 每局允许下注的等待时间 |
| 局间等待 ms | `3500` | 爆炸后到下一局开始的等待时间 |
| 推送频率 ms | `100` | 保留参数；当前玩家端使用事件推送和本地倍率计算 |

### 4.2 下注参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 最小下注 | `1` | 真实玩家最低下注 |
| 最大下注 | `1000` | 真实玩家最高下注 |
| 下注档位 | `10,50,100,500` | 玩家端筹码档位 |
| 初始积分 | `1000` | 新玩家初始余额 |

注意：

- 玩家下注必须命中 `下注档位`。
- 下注档位会被限制在最小下注和最大下注之间。
- 玩家端 `1000` 显示为 `1K`。

### 4.3 奖池参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 奖池余额 | `100000` | 真实玩家提现返还的资金池 |

规则：

- 真实玩家下注进入奖池。
- 真实玩家 Cash Out 从奖池扣除。
- 有真实玩家下注时，爆点会被奖池承受能力限制。
- 机器人不消耗奖池。

### 4.4 爆点参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| House edge bps | `150` | 平台优势，150 bps = 1.5% |
| 1.00 爆炸 bps | `150` | 1.00x 即爆概率 |
| 最大倍率 | `100` | 普通随机爆点上限 |

说明：

- `100 bps = 1%`。
- 普通随机爆点最低为 `1.01x`。
- `1.00x` 只由 `1.00 爆炸 bps` 控制。
- 当前服务端允许最大倍率最高配置到 `1000x`。

### 4.5 机器人参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 机器人最少 | `14` | 每局最少机器人数量 |
| 机器人最多 | `34` | 每局最多机器人数量 |
| 机器人下注最小间隔 ms | `100` | 两个机器人下注之间的最小间隔 |
| 机器人下注最大间隔 ms | `230` | 两个机器人下注之间的最大间隔 |
| 机器人最小下注 | `1` | 机器人下注下限 |
| 机器人最大下注 | `250` | 机器人下注上限 |

规则：

- 机器人下注金额会优先从后台筹码档位中选择。
- 若筹码档位不在机器人下注范围内，会回退到可用筹码档位。
- 机器人按间隔陆续下注。
- 服务端不会在起飞前最后一刻补齐未下注机器人。
- 如果机器人数量过多或间隔过大，服务端会根据下注窗口和最小间隔尽量排满。

### 4.6 纯机器人高飞参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 纯机器人高飞 bps | `800` | 只有机器人下注时触发高飞的概率 |
| 高飞最小倍率 | `100` | 高飞随机爆点下限 |
| 高飞最大倍率 | `500` | 高飞随机爆点上限 |

规则：

- 只要本局有真实玩家下注，就不启用纯机器人高飞。
- 只有机器人下注时，才按概率触发。
- 该能力用于演示气氛，不参与真实玩家公平局。

## 5. 玩家管理

后台玩家列表只包含真实玩家。

余额调整：

- 输入 `100`：给玩家增加 100 积分。
- 输入 `-100`：扣除玩家 100 积分。
- 调整后余额不能小于 0。

使用场景：

- 本地测试补余额。
- 演示时修正余额。
- 模拟运营调整。

## 6. 强制爆炸

使用方式：

- 留空提交：当前回合按当前倍率立即爆炸。
- 填写 `2.50`：将当前回合爆点改为 `2.50x`。

限制：

- 如果火箭已经飞过填写倍率，会以当前倍率为下限。
- 如果有真实玩家下注，还会受奖池承受能力限制。
- 强制爆炸回合不应作为公平随机局验证。

## 7. 暂停和恢复

暂停：

- 不再创建新局。
- 当前局如果已经开始，会继续走完。

恢复：

- 如果没有当前局，会立即创建新局。

## 8. 回合记录

回合记录展示：

- 回合 ID。
- 爆点。
- 总下注。
- 总返还。
- 平台盈亏。
- Hash。

口径：

- 金额只统计真实玩家。
- 机器人金额不记录。
- 记录中可保留真实玩家下注明细，用于本人历史和后台核查。

## 9. 常见问题

### 9.1 为什么玩家端不显示 Hash？

玩家端默认不显示 Hash，避免直播画面拥挤。服务端仍保留公平性数据，并在爆炸后通过接口公开。

### 9.2 为什么后台没有密码？

这是 MVP 本地开发版本。公网部署前必须增加后台登录、权限、2FA、审计和限速。

### 9.3 为什么机器人金额不进平台盈亏？

机器人是演示气氛用的虚拟玩家，不代表真实收入或负债。平台盈亏只统计真实玩家。

### 9.4 为什么有真实玩家时爆点变低？

真实玩家下注后，服务端会计算奖池最多能承受多少返还。如果随机爆点超过奖池承受能力，会被压到奖池上限。

### 9.5 为什么飞行中没有持续推送倍率？

为了降低带宽，服务端只推 `flight_start` 和关键事件。前端用 `launchAt` 和公式自己计算显示倍率。Cash Out 和 Crash 仍由服务端权威结算。

### 9.6 修改参数什么时候生效？

多数参数下一局完整生效。当前已经创建的回合不会全部重算，例如已经生成的机器人计划不会因为后台修改而立刻重排。

### 9.7 机器人还是不够分散怎么办？

调大 `机器人下注最小间隔 ms` 和 `机器人下注最大间隔 ms`。如果下注倒计时太短、机器人数量太多，服务端会根据时间窗口尽量排队，超出可排数量的机器人不会强行补到起飞前最后一刻。
