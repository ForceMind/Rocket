# Rocket 动态风控系统需求

## 1. 概述

本次需求旨在为 Rocket Crash 游戏引入一套**完整的动态风控系统**，通过多维度的 RTP (Return to Player) 监控和动态参数调整，平衡玩家体验与平台收益。保留现有的“奖池上限爆点”及“机器人隔离”机制，通过 9 项新增机制重塑整体风控闭环。

---

## 2. 新增核心功能点详述

### 2.1 今日 RTP 风控 (短期波动管理)

- **目的**：用于平抑单日的异常波动。平台单日亏损时轻微收紧，单日大赚时适度放水提升玩家体验。
- **正常范围**：目标 `96%`，容忍区间 `76% - 116%`（高于 116% 视为平台亏损，低于 76% 视为平台盈利）。
- **生效门槛**：今日真人下注额 ≥ `100,000` 游戏金币 且 完成局数 ≥ `30` 局。不满足则状态记为“样本不足”。

### 2.2 本周 RTP 风控 (整体趋势主导)

- **目的**：判断平台长期的整体盈亏方向。本周数据比今日数据更稳定，因此在决策时**优先级最高**。
- **正常范围**：目标 `96%`，容忍区间 `91% - 101%`（高于 101% 视为平台亏损，低于 91% 视为平台盈利）。
- **生效门槛**：本周真人下注额 ≥ `500,000` 游戏金币 且 完成局数 ≥ `1000` 局。不满足则状态记为“样本不足”。

### 2.3 风控模式切换逻辑

- **目的**：根据今日和本周的 RTP 状态交叉对比，系统将自动切入以下 6 种模式之一：**正常、轻收紧、强收紧、极强收紧、轻放水、强放水**。
- **核心原则**：本周为主，今日为辅。如果本周亏损，绝对优先收紧；如果双周期均亏损，则进入“极强收紧”。

### 2.4 动态平台优势

- **目的**：平台优势（House Edge）决定了普通爆点整体分布的高低。
- **新增机制**：通过风控模式动态下发。平台亏损越多，平台优势数值调得越高，整体爆点表现越被压低；反之亦然。

### 2.5 动态即爆概率 (1.00x)

- **目的**：游戏出现 `1.00x` 直接结束的概率，是最直接、杀伤力最强的止损手段。
- **新增机制**：由风控模式动态决定（例如正常情况为 `1.5%`，极强收紧飙升至 `15.0%`）。
- **新增特例保护**：当**本局总下注额 ≤ 1000 游戏金币**时，视为小额娱乐局，**即爆概率强制归零 (0%)**，保障新手和低成本玩家的体验。

### 2.6 普通爆点随机扣点 (隐性扣点)

- **目的**：在不改变底层生成公式的前提下，为平台增加不易察觉的边际优势。
- **新增机制**：在每次生成的普通随机爆点上，固定随机扣减 `0.01x ~ 0.05x`。即爆局不扣，扣减后的最终值不得低于 1.00x。

### 2.7 单次总赔付上限

- **目的**：资金安全防线。即便奖池极其充裕，也不能容忍单局赔付过度失控。
- **新增机制**：由后台设定固定值（建议 `50000.00` 游戏金币）。
  - `单次上限对应爆点 = 50000.00 / 本局真人总下注`
  - 如果生成的大爆点会导致本局总赔付超过 50000 游戏金币，则修改最大爆点范围。

### 2.8 个人 RTP 单人局风控 (欧皇隔离)

- **目的**：防止运气极佳、个人 RTP 远超大盘的玩家，在自然单人局中持续榨取奖池。
- **触发条件**：本局**仅有 1 名真人玩家**参与，且该玩家个人 RTP ≥ `120%`、历史净赢 ≥ `1000` 游戏金币（需下注超 500、局数超 50）。若有其他真人玩家同局，则该机制失效。
- **惩罚机制**：
  1. 即爆概率额外 `+20%`。
  2. 修改随机数映射上限为 `2.50x`（并在每次应用时随机减去 `0 ~ 1.50`）。

### 2.9 放水预算池机制 (资金流转与熔断)

- **目的**：奖池不能无限膨胀，平台赚多时也必须回馈玩家，建立生态良性循环。同时必须严格控制放水成本。
- **资金来源 (蓄水)**：
  - 当主奖池超过设定的目标金额（如 10000 游戏金币）时，超额部分立刻被抽离：**70% 直接转化为平台实收利润，30% 存入放水预算池**。
- **资金消耗 (放水)**：
  - 只有在触发【轻放水/强放水】模式的对局中，玩家群体产生的**净赢利**（本局总返奖 - 本局总下注）才会从【放水预算池】中实时扣除。
  - 若在放水局中玩家整体依然亏损，则放水预算不增加，正常流入主奖池。
- **局中动态熔断机制 (耗尽即爆)**：
  - 在放水局中，为了防止一局就把放水预算彻底打穿，系统会计算一个**放水预算上限爆点**：
    `放水上限爆点 = (当前放水预算池余额 + 本局真人总下注) / 本局真人总下注`
  - **离开就爆**：在游戏飞行中，如果倍率达到了“放水上限爆点”，意味着预先攒好的放水预算在这一瞬间被完全掏空。此时系统会**强制立刻爆掉**，确保超额的赔付不会去啃食主奖池和平台利润。

## 4. 功能间的协同与配合机制

新引入的 9 大机制并非独立运行，而是通过以下三种协同方式构成严密的风控网：

### 4.1 宏观与微观协同 (双周期制衡)

**“本周保下限，今日做微调”**。本周 RTP 是定海神针，决定大方向（收紧或放水）。但单日往往容易出现剧烈波动，今日 RTP 的存在使得平台可以在大方向下做灵活微调（例如：本周仍在盈利区间，但今天亏损严重，系统会进入“正常”或“轻收紧”模式，暂停放水）。

### 4.2 随机数映射限制 vs. 安全防线硬截断

为了防止被玩家看出破绽（出现满屏的 2.50x 一眼假现象），风控手段被分为了两大层：

- **生成层（曲线柔化）**：像 `后台最大爆点`、风控模式给的 `RTP爆点上限`、个人惩罚 `2.50x`，它们的作用是**修改随机数的映射上限**。通过缩窄随机数生成的上限范围，让最后生成的爆点分布曲线依然是顺滑且自然的。
- **防线层（刚性安全）**：像 `单次总赔付上限` 和 `奖池物理上限`。这两者取决于当局下注金额，瞬息万变，所以它们作为最后一道不可逾越的红线进行**硬性 Min 值截断**。

### 4.3 全局与局部的隔离 (公共池与单人局)

平台放水必须面向所有玩家，平台收紧也可能误伤普通玩家。引入“个人 RTP 单人局风控”做到了完美隔离：即使大盘当前因为赚钱太多正在“强放水”，高 RTP 的危险玩家自己一个人玩时，系统照样会无情地通过 2.50x 映射上限和 +20% 即爆率对其进行收割，且不会影响其他玩家的自然体验。

## 5. 单局逻辑全流程串讲 (执行时序)

每一局游戏开始前到生成爆点，服务器将严格遵循以下计算流程：

1. **下注锁定与数据快照**
   结算完下注阶段，固定本局真人下注额、真人数量、机器人数。此时本局结果未出，不计入周期 RTP。
2. **查表获取风控模式**
   计算满足生效门槛的本周、今日 RTP 状态，查表匹配得出本局的**风控模式**。
   并根据风控模式下发本局的：`平台优势`、`基础即爆概率`、`模式最大爆点上限`、`是否允许消耗放水预算`。
3. **个人风控判定叠加**
   判断是否只有 1 名真人且满足高 RTP。如果满足，将本局即爆概率再 `+ 20%`，并在后续步骤中记录一条 `2.50x (且随机减去0~1.50)` 的个人映射上限。
4. **计算随机数映射上限**
   系统取 `后台全局最大爆点`、`风控模式上限`、`个人高RTP上限` 这三者的**最小值**。
   将这个最小值作为本局随机公式生成的**映射关系上限**，确保生成的爆点平滑且自然，不会出现刻意的平头截断。
5. **生成自然随机爆点**
   - 先以最终合并的概率判定是否 `即爆`（**注意：若本局总下注额 ≤ 1000 游戏金币，即爆概率强制为 0**），命中则爆点直接为 `1.00x`。
   - 若未即爆，则基于步骤 4 得出的映射上限及平台优势，生成一个自然爆点，随后随机扣除 `0.01 ~ 0.05`。
6. **资金安全底线拦截 (Final Min)**
   分别计算以下物理极限值：
   - `单次赔付上限爆点 = 500.00 / 本局真人下注额`
   - `主奖池上限爆点 = 当前可用主奖池 / 本局真人下注额`
   - `放水预算上限爆点`（仅在放水模式下生效）：`= (放水预算余额 + 本局真人下注额) / 本局真人下注额`
   
   将 **第 5 步生成的随机爆点** 与上述适用的安全极限值进行比对，取**最小值**，得出最终呈现在客户端的 `FinalCrash`。这意味着只要触碰到上述任何一个极限倍率，游戏就会瞬间“耗尽即爆”。
7. **记录追溯原因**
   对比最终生效的是哪个限制，记录日志 `Reason`（如触发个人单人局、触碰单次赔付上限、自然随机等），结束判定进入飞行。

## 6. 后台报表与关键配置字典

### 6.1 数据报表需求清单

为支撑风控策略有效性分析，后台数据架构需要新增：

- **总览大盘模块**：今日/本周实时 RTP 及状态、当前触发的风控模式及实时参数、奖池与放水预算池的实时余额。
- **单局审计模块**：单局生成的映射上限、各类截断判定数值、实际输出 FinalCrash 及其触发的限制原因 (Reason)。
- **玩家画像模块**：增加个人 RTP 监控报表，标记“高 RTP”玩家群体，统计单人惩罚局触发频次及最高取现纪录。
- **资金池流水流向**：记录奖池超过目标线后的每日抽水金额、转化为利润的金额以及注入放水池的金额趋势。

|:------------ |:----------- |:----------------------------- |

|              | 今日 RTP 容忍宽幅 | `±20%` (区间: 76% ~ 116%)       |
