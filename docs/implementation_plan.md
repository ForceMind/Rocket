# 后台大盘重构实施计划

根据您的要求，我将对管理后台界面的架构和内容呈现进行全面升级。具体修改方案如下：

## 1. 顶部页签架构调整
原来的菜单结构将被重新梳理，将历史的“数据分析”与实时的“游戏状态”彻底分离：
- **[原] 数据总览** -> **[新] 游戏状态 (Game Status)**：专门用于监控当前游戏大盘、资金水位和本局状态。
- **[新增] 数据看板 (Analytics)**：将每日数据、玩家数据、历史局数提升为独立的主级页签，并增加数据汇总区。
- 保留：玩家管理、资金管理、参数配置。同时，原先单独的“当前对局”将合并入“游戏状态”中，避免界面过于碎片化。

## 2. “游戏状态”面板内容升级
原先仅显示几个简单的状态块，现在将增加更多维度的实时数据：
- **顶部核心指标排布 (Metric Banner)**：
  - 放水预算池余额
  - 本局大盘风控模式
  - 平台 7 天 RTP、平台 24h RTP（新拆分显示长短线走势）
  - 今日总下注、今日总派彩、平台净利润（新增显示实时盈利）
- **当前对局精细监控 (Live Round Dashboard)**：
  - 状态追踪：回合 ID、当前状态（等待下注/飞行中/已爆炸）、当前倍率。
  - 爆点预先监控：本局自然生成的爆点、风控后执行的真实爆点、硬控原因（如放水池容量、单人防守等）。
  - 下注追踪：**新增本局真人总下注金额、机器人下注金额展示**。
  - 强制爆炸干预与游戏启停控制器。

## 3. “数据看板”分类与全面化
提升为独立顶部页签后，进行合理分类：
- **数据过滤器**：保留日期区间与玩家筛选，并新增“快速筛选”按钮（如今天、过去7天等）。
- **分类页签 (Inner Tabs)**：
  - **总况与每日报表**：在原每日报表的基础上，增加表头的“区间汇总卡片”（如选定区间内的总流水、总局数、总 RTP），让管理者一目了然。
  - **玩家多维分析**：左侧展示玩家列表与总盈亏，点击后右侧展示该玩家按天和按局的明细流水，优化排版。
  - **历史全量局数**：罗列每一局的真人/机器人参战详情与结果，用于查证复盘。

## 执行计划
1. 修改 `public/admin.html`，重组导航栏与容器，新增所需的展示节点。
2. 修改 `public/admin.js`，更新 `render()` 函数群，补充“游戏状态”所需的新字段绑定（从现有的 adminSnapshot 中提取）。
3. 调整样式文件，确保新的“游戏状态”与“数据看板”排版大气、紧凑且专业。
